# Dotfiles Camilosar

My personal configs for my most used programs

## Install

Run this:

```
git clone https://github.com/camilo-845/Dotfiles.git ~/.dotfiles
```

Move to `~/.dotfiles`

````sh
cd ~/.dotfiles

install with stow

```sh
stow .
````
